# Stage Clock brand

- `mark.svg` — the clock mark on its own (transparent). Use at any size.
- `logo-dark.png` / `logo-light.png` — mark + wordmark, 1520×260, transparent, for dark and light backgrounds.
- `social-preview.png` — 1280×640 for GitHub's social preview, Product Hunt, Twitter cards.
- Wordmark face: Barlow Semi Condensed 700. Colors: background `#0b0d10`, ink `#ffffff`, red `#ff2d2d`, ring `#2a323b`.
