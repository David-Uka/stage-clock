    On the venue Wi-Fi · desktop app

    Any phone, tablet or laptop on this Wi-Fi can show the speaker display. Scan the code or open the link. No internet needed.

    No displays connected

    Remote displays over the venue Wi-Fi need the desktop app (Windows, macOS or Linux download). In the browser, use "Open display window" on this computer.

    Anywhere · room code

    Needs internet on both ends. The display opens the link or enters the code at the Stage Clock website. Devices connect to each other directly; the public PeerJS service only introduces them.
