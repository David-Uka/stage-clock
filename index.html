    How this works· same Wi-Fi, no internet needed

    The desktop app serves the display on this computer's network address. Any phone, tablet, laptop or Raspberry Pi on the same Wi-Fi scans the code or opens the link. Windows may ask once to allow Stage Clock through the firewall; allow it for private networks.

    How this works· needs internet on both ends · devices connect directly, PeerJS only introduces them

    The display opens the link, scans the code, or enters the six-character code at the Stage Clock website. The two devices then talk to each other directly over WebRTC. The public PeerJS service only introduces them and never sees the timer data.

    How this works· a relay server you run · no third party

    Getting started
    1. Build the rundown with + Add timer, or Import a saved one.
    2. Open display window and drag it to the projector or second screen. Phones and other screens connect from Remote displays.
    3. Press Start to run the clock and Next for the next timer. Every alert is visual; nothing makes a sound.
